# یادآور شمسی (Yadavar Shamsi)

اپ اندروید یادآور با تقویم شمسی، چک‌لیست، زنگ/اعلان با Snooze، تایپ صوتی و ویجت Glance.

## ساخت APK با GitHub Actions
1. این پوشه را به‌عنوان ریشهٔ یک مخزن جدید در GitHub آپلود/پوش کنید.
2. تب **Actions** ← workflow به نام **Build APK** ← **Run workflow** (یا با هر push روی main خودکار اجرا می‌شود).
3. بعد از پایان، از انتهای صفحهٔ اجرا، بخش **Artifacts** فایل `YadavarShamsi-apk` را دانلود کنید.

APK با کلید debug امضا می‌شود و برای نصب مستقیم روی گوشی مناسب است (نه انتشار در استور).

## ساختار
- `core/` تقویم جلالی و پارس گفتار فارسی
- `data/` دیتابیس Room، تنظیمات، عملیات یادآور
- `alarm/` زمان‌بندی دقیق، اعلان، صفحهٔ آلارم و Snooze
- `widget/` ویجت Glance (تیک، باز/بسته کردن زیرمجموعه، اندازهٔ فونت)
- `ui/` صفحات Compose
